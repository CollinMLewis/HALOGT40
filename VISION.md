# HaloGT40 Vision

HaloGT40 is a personal AI agent that lives on your devices — starting with Android.

It does real work instead of just answering questions.  
It keeps working when the app is closed.  
It remembers you in files you can read and edit.  
It always asks before anything you cannot undo.  
No one can tell which model is running underneath. Everything goes through the Halo Engine.

**Core principles**
- Android-first, phone-native experience
- Local-first with optional self-hosted relay
- Complete model opacity (Halo Engine)
- Human-readable memory and full user control
- Beautiful, fast, premium feel
- Asks before irreversible actions (Sentinel++)

We are building the agent people actually live with on their phone.
