# HaloGT40

**HaloGT40** is a personal AI agent that lives on your devices — starting with Android.

It does real work instead of just answering questions.  
It keeps working when the app is closed.  
It remembers you in files you can read and edit.  
It always asks before anything you cannot undo.  
You choose which models Halo can use for each task.
